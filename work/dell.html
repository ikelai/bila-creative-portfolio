Project / Technology · Global Brand

Dell Technologies

品牌在地化 · 型錄系統 · EC 內容

Overview

為全球科技品牌 Dell Technologies 建立台灣市場的型錄、EC 與平面製作系統。從國際品牌規範落地到本地執行，以一致、可複用的設計架構，支撐龐大產品線的長期溝通。

ClientDell Technologies（必樂為契約主體）
Scope型錄系統 / EC 內容 / 品牌在地化
Scale長期合作 · 15,000+ 檔製作紀錄

問題

國際品牌素材與台灣市場需求之間存在巨大落差：產品線橫跨筆電、桌機、伺服器、螢幕與周邊，每一季都有大量型錄、EC 頁面與通路素材需要在地化。

原廠品牌規範（Brand Identity System）嚴謹且複雜，若沒有穩定的製作系統，每次產出都容易失準、耗時。

方法

以品牌規範為基底，建立台灣市場可複用的設計系統：型錄版型、EC 產品頁模板、DM 與通路素材的統一架構。

以季度為節奏的提案—迭代—完稿流程，確保大量產出維持品質一致。

  • A3 型錄提案與多次修提迭代（0617 → 0618 V1/V1.1 → 0818）
  • Q1／Q2／Q3 季度型錄完稿與 mockup
  • EC 產品頁、Banner 與通路素材在地化

成果

以嚴謹的製作系統支撐全球品牌的台灣市場溝通，讓每一季的大型產出都能準時、一致地交付。
